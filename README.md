**Employee Monitoring System (Real-Time Behavioral Analysis)**
A real-time Employee Monitoring Dashboard built using Python (Tkinter) that tracks employee activity, detects usage of forbidden applications, and analyzes behavioral patterns using multiple performance metrics. The system is designed for productivity monitoring and security-focused environments such as SOC or enterprise workforce tracking

**Features**
 Real-time employee activity monitoring  
 Detection of forbidden applications (YouTube, Instagram, etc.)  
 Behavioral metrics analysis:
 Login frequency  
 Action speed  
 Service diversity  
 Session irregularity  
 Behavioral deviation  
 Live alerts for suspicious activity  
 Sound notification on violation  
 Modern dark-themed dashboard UI  
 Rule-based behavior evaluation system  

- Python  
- Tkinter (GUI)  
- pygetwindow (window monitoring)  
- datetime module  
- winsound (alert system)

**Execution:-**
cd employee-monitoring-system
pip install -r requirements.txt
python main.py
